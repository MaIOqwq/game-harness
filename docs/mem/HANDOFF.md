- **原来为什么扛不住追问**：`messages` 里只有 `[system] + 最近 3 轮原话 + 本轮问句`。更早的题只能靠状态卡

- **捉到的 bug ①：网页后端拉爬虫用的是"错的那个解释器"。** 8780 原先跑在 `<系统 Python 解释器>` 下，

## 现态（2026-09-14 08:1x — 爬虫改成**按需启停**：平时不在跑，要用才拉、闲下来自己关）

> 本次更新：不再「开一次就一直占内存」。`start.bat` 现在**只起网页后端**，两个爬虫交给它按需拉。
