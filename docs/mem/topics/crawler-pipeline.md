# 爬虫关键词 / 搜索管道

真源：`harness/sources/live.py:154`；`PLAN.md §8.2`、`§9`、`§10.1`(9/4)；`crawlers/README.md`。本文件存结论 + 血泪教训。

## 结论（代码已实现）
- **关键词 = 游戏名 + 词条直接拼接，全去空格**：`re.sub(r"\s+","", "%s%s" % (g, q))`。留空格反而漏匹配（实测：去空格是用户纠正过的硬教训）。
- LLM 只见 `{query}`（一次一主题、禁指令/指代）；平台由引擎规约，数值参数不进 LLM 视野。
- B站按综合排序、每视频一级评论上限、爬距/冷却受闸门控；NGA 纯词自动加 `search|`。
- 别名/指代先解（"三蹦子"→崩坏三），解不了宁可不答不瞎搜。

## 血泪教训
- **死 SESSDATA 比不登录更狠**：bili 降权到 3 条/页。修复路径 = 清死 profile → QR 扫码（见 PLAN §9）。登录态 = 服务器唯一 owner，绝不拷回。
- **量级先对齐**：曾擅自把单动态拉到 1600 条被斥"你疯了"；宁 25 条热度排序。用户说"多拉一点"是温和增量，不是让拍工程级量级。
- 造词别自造：宁用用户原话/实测命中过的词，别拍脑袋写"XX版本评价"带空格（会漏匹配）。
