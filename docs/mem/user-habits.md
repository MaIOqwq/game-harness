# user-habits.md — 与用户协作的个人规则

> 2026-09-08 从历史反馈条目编译。每条都是 MUST/FORBIDDEN，不是参考建议。与 `PROJECT_MEMORY.md §5` 铁律叠加。

## 沟通 / 格式
1. **每条回复首行写当前北京时间 `[HH:mm]`**。（feedback-show-time）
2. **聊天桥（飞书/微信）里禁 AskUserQuestion 弹窗**。要用户决策就纯文字编号列问题 + 选项（A/B/C…），写清"回复序号即可"，然后**停下等回复**，不许自作主张按推荐继续；多个决策一次性列完。（feedback-no-picker-ask-in-text）
3. 回复简洁，适合聊天窗口读；禁口号/中二/营销腔，事实够硬不需要形容词包装。（feedback-no-hype-phrasing）
3b. **说人话**：①**禁中英夹杂**——中文句子里不塞英文词（mock/runbook/gate/trace/token/scope/case/demo…），先想中文说法（假参考样本/检查关卡/记录流水/用量/范围/演示）；代码标识符绕开描述或当场解释。②少用项目内部代号行话（M1.1、硬尾之类），名词首次出现先一句大白话解释。③面向用户的回复不堆里程碑编号。原话锚点："你说话能不能正常点?"、"你别给我整这种黑话…说一句话不夹着英语会死?"（2026-09-10）。

## 动手前
4. 用户说"看记录/查聊天/搜记忆" → **必须先真读记录再动手**，禁止跳过直接部署/修改。（feedback-read-history-first）
5. 改正在运行的脚本/链路只做明确要求的改动；不顺手"改进"相邻代码；不自作主张扩范围。（surgical 教训：发送脚本反复改坏）
6. 开工新功能前**先把整体架构/技术栈与用户对齐再编码**——别急着写实现。原话锚点："我们应该先讨论好整体架构和技术栈，再去做详细编码"（2026-09-06）。
7. "多拉一点/深采" = 相对轻采样的温和增量，**采集量级先与用户确认再跑**，不自己拍工程级量级（曾擅自 1600 条/动态被斥）。（feedback-collect-scale-align）
8. 复用场景先找毕设/现成里"复制改造"的对应物，**搬它真正的业务逻辑**，别借壳另写；交代血缘要精确（字节复制/继承哪些/新写哪些），被翻旧账认账改口、不狡辩。（feedback-code-provenance）
9. 安全/边界类需求用户说"考虑所有情况" → 枚举身份矩阵（未登录/普通用户/内部角色）+ 绕过向量（伪造 token/越权传参/拒绝响应泄露），优先**结构性防线**而非 prompt 劝告。（feedback-consider-all-cases）
10. **动 演示服务器/生产服务器 前先评估会不会把服务器干 OOM 崩溃——这是重点，必须考虑**：生产服务器 是 2c4g 满载生产（上面跑着若干生产服务）、演示服务器 是 4c8g 也扛着爬虫+nlp 常驻；重命令（`find /`、训练/批量推理、大 mysqldump/scp、导入/向量化、并行任务）前先 `free -h`/`nproc` 看余量并先与用户对量级；长任务带 timeout/nohup、单进程跑（双进程并发打同隧道曾 429）。用户原话锚点："每次进行操作之前考虑会不会导致服务器oom崩溃，这是重点，必须考虑"（2026-09-08）。（feedback-oom-before-ops）

## 事实纪律
11. 不编数字/结论/onset/URL；性能数字可溯源，查不到就删或改定性。（feedback-no-fabricated-numbers）
12. 明文 cookie/token **绝不进对话/日志/文件**；X-Token 只在服务器本地读；bili 登录态 = 服务器唯一 owner，绝不拷回本地/仓库。（PROJECT_MEMORY §5）
13. 毕设原版一行不动，改动只落 `/opt/<nga-crawler-copy>`、`/opt/<bili-crawler-copy>` 副本。

## 记忆纪律（本项目的核心诉求）
14. **长项目中间态不许只靠 claudecode 自带记忆**（MEMORY.md/压缩摘要，用户明确"用着太难受"）：里程碑/收尾/切换前把「当前任务 / 刚定决策 / 下一步 / 卡点」落 `docs/mem/HANDOFF.md`（现态）或 `PLAN.md §10`（决策日志）。（feedback-long-project-memory）
15. 会话开始先读 HANDOFF 尾 + RECALL + PLAN §10 尾回灌，别凭压缩摘要猜。
16. 未经明确允许不 git push；LoRA/训练/大规模运行须用户明确指令，禁止自动跑。
