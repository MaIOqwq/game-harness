# 社区回顾 · 一页模板

> 用途：**短汇报**（不是问答题）。问答是别人问、我们去找；汇报是我们自己判断哪个值得说。
> 栏目**固定**，才能跟上一期对得上；**数字全部可点回原文**，不许编。
> 括号里是占位符。数字一律真跑才填 —— 宁缺，不编。

**窗口怎么定**：以版本为轴，**更新前 7～14 天 + 更新后 7～14 天**（不是随手挑七天）。
版本时间锚点从官号动态取（哪天发的公告/动态），拿不到就写明"版本日未定，窗口按自然周"。

**时长**：一页。超了就说明收录规则没收紧，不是内容不够写。

---

## 〔游戏名〕〔版本号 / 时段〕社区回顾

窗口：〔YYYY-MM-DD ～ YYYY-MM-DD〕　采集：NGA 〔n〕条 / B站 〔m〕条　生成：〔YYYY-MM-DD HH:MM〕

**一句话**：这个窗口社区主要在争〔什么〕，热度比上一窗口〔升 / 降 / 平〕，〔哪一侧更热〕。

### ① 主要在说什么

〔2～4 条。每条 = 口径 + 量级 + 代表原文。〕

- 〔口径 A〕 —— NGA 〔n〕条 / B站 〔m〕条 这么说，代表〔[id=N]〕〔[id=M]〕
- 〔口径 B〕 —— NGA 〔n〕条 / B站 〔m〕条，代表〔[id=N]〕
- 〔口径 C〕 —— NGA 〔n〕条 / B站 〔m〕条，代表〔[id=N]〕

### ② 两个平台分开说

〔不许合并成一句"社区说"。两侧的角色不一样。〕

- **NGA**（偏讨论、会给方案）：主流口径是〔…〕。其中给出具体调整建议/数值依据的有 〔n〕条，代表〔[id=N]〕。
- **B站**（偏放大、靠视频传）：头部视频在说〔…〕，代表〔[id=N]〕。
  - 本轮有没有**讲解类视频**起来：〔有（[id=N]，播放 〔x〕 / 评论 〔y〕）/ 无〕。

### ③ 攻略口径分歧

〔攻略/强度这类**不按好评差评报，按分歧报**。〕

- 对象：〔角色 / 配队 / 玩法 / 版本内容〕
- 口径一：〔…〕，代表〔[id=N]〕
- 口径二：〔…〕，代表〔[id=N]〕
- **分歧卡在哪**：〔前提不同：泛用 vs 极限 / 练度不同 / 适用范围没写清〕
- **适用范围提醒**：上面两种口径分别针对〔什么环境 / 什么练度〕
- 〔若本轮只有一种口径〕→ 写「本轮无分歧」，**不要硬凑**。

### ④ 异常与下一步

- 〔某条动态 / 某条视频 / 某个话题〕量级明显超基准：基准线〔x〕、实际〔y〕，代表〔[id=N]〕。
  - **是爆款还是节奏**：〔能区分 → 写明理由 / 证据不足 → 写"先存疑"〕
- 下一步盯：〔哪个点、哪一侧平台、看什么信号〕。

### ⑤ 缺口与滞后

〔**只要有一项不满足就得写**；一项没有就写"无"。这一栏最容易被省，也最决定这份东西可不可信。〕

- 平台覆盖：〔某侧本轮没取到 / 未登录 / 被风控〕
- 时段覆盖：〔窗口没翻到头，更早的没采到〕
- 度量口径：〔情感是**关键词降级**，不是模型算的〕
- 样本滞后：〔采集时刻距现在多久〕

### ⑥ 引用清单

〔①②③④里出现过的**每一个编号**都要在这一栏能查到出处，可点开原文。〕

| 编号 | 平台 | 出处 | 时间 |
|---|---|---|---|
| [id=〔N〕] | 〔NGA / B站〕 | 〔标题或摘要〕 | 〔YYYY-MM-DD〕 |

## 附录 A · 收录判据（哪条进哪栏，先定死）

判据不定死，汇报就会变成流水账。

| 栏目 | 准入条件 | 不够条件怎么办 |
|---|---|---|
| ① 主要在说什么 | **两个平台都出现**的口径，且每侧至少 2 条独立原文 | 单平台才有的，降级到②，不占①的位置 |
| ② 平台分开说 | NGA 侧只收**有具体方案/数值讨论**的；B站侧只收**量级高于同窗口中位数**的视频 | 该侧本轮没有就说"该侧本轮无" |
| ③ 攻略分歧 | 同一个对象出现**两种以上互斥口径**才算"分歧" | 只有一种口径 → 写"本轮无分歧" |
| ④ 异常 | 量级**超基准线**才报；必须回答"爆款还是节奏" | 分不清就写"先存疑"，**不许默认是节奏** |
| ⑤ 缺口 | **强制栏**，不看有没有料 | 没缺口写"无" |
| ⑥ 引用清单 | **强制栏**，①②③④提到的编号一个都不能漏 | —— |

## 附录 B · 四条硬规矩（「正经」跟「营销号总结」的分界）

1. **带量级** —— 写"NGA 30 条里 22 条"，不写"很多人"。
2. **带时段** —— 每句话都能回答"哪段时间"。
3. **带缺口** —— 没采到的平台、没翻到的时段，主动说。
4. **可点回原文** —— 每个数字、每条口径，都能追到一个编号。

## 附录 C · 写法禁忌

- 不用「很多人 / 大家 / 普遍认为 / 引发热议」这类词 —— 它们把"有多少"这件事藏起来了。
- 不用形容词代替数字（"讨论非常激烈" → 换成条数与基准线差多少）。
- **不把单平台说成全社区**（B站热 ≠ 社区全在说）。
- 攻略类**不写"好评/差评"**，写"口径一 / 口径二 + 分歧前提"。
- **不把"爆款"读成"节奏"** —— 播放/评论自然高，跟"有人在带"是两回事。
- 度量是关键词降级时，**不许写成"情感分析显示"**。
